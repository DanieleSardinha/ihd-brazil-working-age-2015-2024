# Data access

This repository does not redistribute raw individual-level mortality records or other source microdata.

The study uses publicly accessible Brazilian health and demographic data from:

- SIM – Mortality Information System / DATASUS
- SIH/SUS – Hospital Information System / DATASUS
- IBGE population projections
- PNAD Contínua
- IPCA

The analytical scripts describe the procedures used to identify eligible records, construct denominators, and reproduce the analyses reported in the manuscript.

Users wishing to reproduce the study should obtain the original source data directly from the corresponding official Brazilian data systems.
